# AZLAN.DEV — SSH Terminal

## Features

- **Interactive Portfolio** — Clean, minimal design with Japanese pixel art aesthetics
- **SSH Terminal** — Full terminal emulator with command-line navigation
- **Secret Game** — Hidden Konami code easter egg (try ↑↑↓↓←→←→BA)
- **Falling Sakura** — Animated pixel art cherry blossom petals
- **Responsive** — Works on all screen sizes

## SSH Terminal Commands

The terminal can be opened by clicking the `ssh` button in the nav bar or the terminal icon in the bottom-right corner.

### Navigation

| Command | Description |
|---------|-------------|
| `help` | Show all available commands |
| `ls` | List files and directories |
| `cat <file>` | Read file contents |
| `cd <dir>` | Change directory |
| `pwd` | Print working directory |

### Portfolio Content

| Command | Description |
|---------|-------------|
| `whoami` | About Azlan |
| `neofetch` | System info with ASCII art |
| `banner` | Display AZLAN banner |

### Pixel Art

| Command | Description |
|---------|-------------|
| `sakura` | Display sakura blossom |
| `lantern` | Display pixel lantern |
| `mountain` | Display pixel mountain |
| `pixel` | Show pixel art |

### Fun Stuff

| Command | Description |
|---------|-------------|
| `game` | Launch the hidden sakura catch game |
| `sudo <cmd>` | Try it... ;) |
| `ping <host>` | Ping a host |
| `curl <url>` | Fetch a URL |

### System

| Command | Description |
|---------|-------------|
| `date` | Current date/time |
| `echo <text>` | Echo text back |
| `uname` | System information |
| `uptime` | Session uptime |
| `clear` | Clear the terminal |
| `exit` | Close the terminal |

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Fonts**: Inter + JetBrains Mono

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```


1. Push to GitHub
2. Import repo on Vercel
3. Deploy — done!
